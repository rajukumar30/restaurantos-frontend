# RestaurantOS design system

## Product personality
Warm, contemporary, food-first and operationally clear. Avoid generic admin-template styling.

## Tokens
- Ink: #171916
- Cream: #F7F4EC
- Paper: #FFFEFA
- Coral: #E56A42
- Herb: #527A5B
- Gold: #E6B85C
- Border: #E9E5DC

## Typography
Use a clean sans-serif stack with strong hierarchy, compact labels and tabular numerals for financial values. Prefer Manrope/Inter-like proportions.

## Panel direction
- Customer: warm, image-led, mobile-first.
- Kitchen: dark, high-contrast, large status controls and timers.
- Owner: editorial analytics, restrained charts and useful density.
- Platform admin: efficient tenant operations and account management.

## Interaction rules
- Every visible control must have a real action before release.
- Provide hover, focus-visible, disabled, loading and error states.
- Maintain keyboard accessibility and readable contrast.
- Responsive layouts must work on phones, tablets and desktop.
- Never present demo metrics as live business data.
